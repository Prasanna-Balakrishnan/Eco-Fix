# 🌍 Eco-Fix

Eco-Fix is a responsive web application built to promote sustainability and eco-friendly practices. It provides an intuitive interface for users to explore, manage, and implement green solutions.

---

## ✨ Features

- **Interactive UI:** Clean and responsive frontend built using modern HTML, CSS, and JavaScript.
- **Node.js Backend:** Efficient and scalable server-side logic handling core application functionality.
- **Docker Integration:** Fully containerized environment using Docker Compose for seamless deployment.
- **Cross-Platform Compatibility:** Optimized for desktop, tablet, and mobile devices.

---

## 🛠️ Tech Stack

**Frontend:**  
HTML5 · CSS3 · JavaScript  

**Backend:**  
Node.js  

**Containerization:**  
Docker · Docker Compose  

---

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or newer recommended)
- Docker and Docker Compose (optional)

---

## 💻 Local Setup (Without Docker)

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Prasanna-Balakrishnan/Eco-Fix.git
cd Eco-Fix
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Run the Application

```bash
npm start
```

### 4️⃣ Open in Browser

Visit:  
http://localhost:3000

---

## 🐳 Docker Setup

### 1️⃣ Build and Run

```bash
docker compose up --build
```

### 2️⃣ Open in Browser

http://localhost:3000
